# 점수 재기획 시뮬레이션 첫 결과 (v_0.15.1, 2026-11-11)

재현: `npm run score:sim -- --runs=40 --seed=1` 과 `npm run score:sim -- --curves --runs=40`.
모든 수치는 `SCORE_REDESIGN.md`의 초안 그대로이고, 기획안에 없던 값(손패 3장, 클리어 돈 4, 단어 가격 4, 소품 6,
초과 문장 하트 4조각 등)은 `src/score/data.ts`·`src/score/shop.ts` 상수다. **아직 아무 수치도 조정하지 않았다.**

## 요약

1. **아무 봇도 10층을 넘지 못한다(승률 0%, 평균 5~6층).** 점수가 목표만큼 자라지 않는다. 덱 크기는 9장에서 거의
   그대로이고 유물은 평균 1개 미만이다. 한 판에 버는 돈(약 5~6)에 비해 물건이 비싸서 성장이 막힌다.
   목표 곡선(§1)은 15층 90,000을 가정하지만 8층에서 낸 점수가 약 1,900이다.
2. **아이템(스탯)이 구매의 절반 이상**(아이템 1,029 · 스티커 692 · 단어 209 · 유물 149). §15의 "아이템 스탯 편중"이
   이 엔진에서도 재현된다. 재련은 분노·기본 가산·용돈에 몰린다.
3. **한 감정 덱 비교에서 분노가 모든 형태에서 1위**(장마만 슬픔이 근소하게 앞섬). 슬픔/분노 점수비는 기회 2·3·5·10번에서
   0.42 · 0.47 · 0.70 · 1.06으로 기획안 모델값(0.63 · 1.06 · 1.43 · 1.93)보다 한참 낮다. 기쁨·즐거움·혼돈은 분노의 절반 안팎.
   단, 봇은 한 문장 앞만 보고 눈물을 약간만 쳐 주므로 슬픔 저축을 덜 쓴다(봇 한계일 수 있음).
4. **시작 카드가 끝까지 정답**: 10층에 닿은 판에서 화가 난 나는·어제의 나는·꾹·단단히·감쌌다·때렸다가 그대로 쓰였다(§15와 같은 구멍).
5. **안 쓰인 카드 17장**: 겹쳐 입은 나는, 고개 숙인 나는, 안도한 나는, 장난꾸러기 나는, 우연히 만난 나는, 세 번째 나는,
   쓸쓸히, 애써, 환하게, 포근하게, 웃으며, 경쾌하게, 하필이면, 삼켰다, 되새겼다, 품었다, 던졌다.
   대부분 단어 구매 자체가 적어서(덱에 들어오지 않아서)다.
6. **스티커 편중**: -도·-만·-듯·-구나·-까지에 몰리고 -다가·-ㄹ 것이다·-자·-조차는 거의 안 산다.
7. **유물**: 쉼표·마침표(칩 고정 가산)만 산다. 곱셈 유물은 칩이 작은 초반에 써 보기 값이 낮게 나온다.
8. 소프트락 0회(상점 대응 카드 보장 규칙 포함). 무작위 봇은 평균 4층으로 다른 봇보다 낮아 선택의 의미는 있다.

## 다음 조정 후보 (아직 적용 안 함)

- 경제: 클리어 돈·남은 기회 보상을 올리거나 단어 가격을 내려 덱이 실제로 자라게 한 뒤 다시 본다(가장 먼저).
- 목표 곡선: 봇 성장 곡선이 잡힌 뒤 층별 `점수/목표`가 1.1~1.3 근처가 되게 `floors.csv`를 맞춘다.
- 분노 약화 또는 다른 감정 강화: 화가 난 나는(첫 문장 +1.8)·냅다(×1.8)·이판사판(×2)의 위치 보너스가 겹친다.
- 봇: 2~3문장 앞을 보는 계획 봇을 추가해 슬픔 저축·예고(-ㄹ 것이다)를 공정하게 평가한다.
